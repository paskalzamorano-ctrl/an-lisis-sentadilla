*Análisis Biomecánico - Sentadilla*

Esta es una interfaz web desarrollada para el análisis biomecánico de la sentadilla evaluando variables cuantitativas en el plano sagital y frontal simultáneamente. 

El sistema utiliza la inteligencia artificial de MediaPipe (visión computacional) para realizar un seguimiento del cuerpo, calcular los ángulos de las articulaciones y detectar posibles asimetrías o valgo de rodilla.

 ## Requisitos para el uso
1. Un navegador web actualizado (Google Chrome o Microsoft Edge recomendados).
2. Dos videos del sujeto realizando la sentadilla (uno de frente y uno de perfil).
3. **Importante:** Los videos deben estar grabados en **cámara lenta (slow motion)** para asegurar la máxima precisión en la captura de ángulos cuadro por cuadro.
4. Uso de marcadores articulares para referencia visual.

### Instrucciones de ejecución
1. Ingresar a la interfaz web pública.
2. Subir el video de perfil en el selector "Sagital" y el video de frente en el selector "Frontal".
3. Utilizar el botón de "Reproducir / Pausar" para avanzar el análisis.
4. En el punto de máxima flexión (fase crítica), pausar el video y presionar el botón de "Capturar Resultados" para obtener las métricas finales.
